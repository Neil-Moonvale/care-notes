# Security and sensitive information

Use fictional examples in public issues, tests and demonstrations. Never upload medical records, identifying screenshots or API keys.

Browser records are unencrypted. Backups include full capture paragraphs and correction history. Anyone with access to the browser profile may access records, including offline. This prototype has no app-level encryption, accounts or cross-device sync.

The optional AI server is restricted to personal loopback use. Do not expose it publicly. Hosted AI needs authentication, per-user quotas and operational checks. Keys belong only in server configuration; no live credentials are included.

For vulnerabilities, use GitHub private vulnerability reporting if enabled. Otherwise open a minimal issue requesting a private contact channel, without sensitive details, exploits or credentials. No response-time guarantee is offered.

中文：公开反馈只用虚构信息。漏洞优先私密报告；没有私密入口时只提出联系请求，不公开个人资料或利用细节。
