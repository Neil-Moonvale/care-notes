# Contributing / 参与改进

Please use fictional data only. 请仅使用虚构数据。

For an issue, include the browser, device, steps, expected behavior and observed behavior. Do not include real names, medical documents, credentials or identifying screenshots.

Before changing summary logic, run `npm test` and add a focused regression case if needed. Preserve original wording, explicit uncertainty and source references. Never infer that an unrecorded event did not happen. Retain conflicting accounts without deciding who is correct.

Useful early feedback: How long does recording take? Can you find the source of each summary item? Do filters or export omit something you intended to share? Is a label confusing? Can you restore a backup in another browser?

Review accessibility with keyboard navigation, readable text, zoom and mobile touch targets. Keep runtime dependencies and external data transfers minimal.
