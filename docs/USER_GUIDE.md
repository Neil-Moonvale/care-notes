## 简体中文

Care Notes 用来整理照护记录、核对不同描述，并准备交接或就诊材料。手机、平板和电脑浏览器都可以使用。当前提供网页版，没有发布安卓安装包。

### 第一次使用

1. 打开应用，选择“体验示例”。这些是虚构数据，可以修改。右上角“怎么用”随时打开说明。
2. 在“整理经过”勾选要放进交接的记录，查看“还需要核实什么”。日期和来源不清楚时，保持未知即可。
3. “可能属于同一段变化”只是候选。看过两条原始记录后再选择“关联这两条”或“不是同一段”；系统不会自动合并。
4. 对已经关联的描述补充核对说明。无法确定谁说得对时，两条都保留。
5. 点“下载交接内容”。文件在手机浏览器的“下载”中；阅读后再分享。

### 开始自己的记录

切换到“我的记录”，点“写一段描述”，粘贴或输入已有观察。整理后逐条检查原话、日期、来源和类别，勾选确认并保存。也可以在“记录”页面逐条新增或更正。

“导出”可以选择记录、下载文本，或在浏览器支持时打印为 PDF。示例与真实记录分开保存，不会因为切换模式混在一起。

### 语言、数据和访问

- 右上角可选择简体中文、English、Español、Français、日本語或한국어。界面、帮助和自带示例一起切换；各语言示例分别保存修改。
- 自己写的记录保持原话。界面翻译不等于原始记录翻译，也不意味着本地文本归类已经验证所有语言。
- “设置 → 导出备份”保存完整数据。“导入备份”会在确认后替换当前真实记录。换设备、换浏览器或清理数据前先备份。
- 数据保存在当前浏览器，不会自动同步。手机和电脑打开同一个地址，并不会自动看到相同的真实记录。
- 私人试用链接需要托管平台验证访问者身份；这不是 Remote，也不要求连接电脑。支持的手机浏览器可以添加到主屏幕。

### 当前能力

当前试用版使用本地规则整理记录，没有启用在线 AI，也没有自动诊断、换药或住院决策。事件关联候选必须由人确认。原文和更正历史可以查回，但来源编号不证明内容正确。复诊前请核对导出材料。

## English

Care Notes organizes care accounts for review and handoff. Use a phone, tablet or desktop browser. No Android installation package has been released.

1. Choose **Try the demo**. All sample records are fictional. Open **How to use** at any time.
2. In **Review an episode**, select records and check the clarification questions.
3. A **may belong to the same change period** item is only a review candidate. Read both source records before choosing **Link these records** or **Not the same period**; the app never links them automatically.
4. Add a review note for accounts you have linked. Retain unresolved differences.
5. Select **Download handoff**. Find the file in your browser’s Downloads and read it before sharing.

For your own observations, switch to **My records → Write an account**. Prepare drafts, check every source, date and category, then confirm and save. **Timeline** provides individual recording and correction. **Export** provides selected summaries and browser print-to-PDF.

The language selector supports Simplified Chinese, English, Spanish, French, Japanese and Korean. The interface, in-app help and fictional examples change language and each language’s demo edits are stored separately. Your own records are never translated by switching language. Local classification patterns remain primarily Chinese/English, so manually review draft categories and sources in other languages.

Use **Settings → Export backup** before clearing the browser or changing devices. **Import backup** replaces personal records after confirmation. Records are stored in one browser, unencrypted, without automatic device sync. Private trial access may require platform sign-in; it does not require Remote or a connected computer.

This trial uses local rules, without online AI, automatic clinical conclusions, diagnosis, medication advice or hospital-admission decisions. Review the original evidence before sharing a summary.

## Español

Care Notes organiza relatos sobre los cuidados para revisarlos y preparar informes. Funciona en el navegador del móvil, la tableta o el ordenador. No se ha publicado un paquete de instalación para Android.

1. Elige **Ver ejemplo**. Todos los registros son ficticios. Puedes abrir **Cómo usarlo** en cualquier momento.
2. En **Revisar un episodio**, selecciona los registros y lee las preguntas pendientes.
3. Un candidato de **mismo período de cambio** es solo una sugerencia para revisar. Lee las dos fuentes antes de elegir **Vincular estos registros** o **No es el mismo período**; la aplicación nunca los vincula automáticamente.
4. Añade una aclaración para los relatos vinculados y conserva las diferencias que no se puedan resolver.
5. Elige **Descargar informe**. Busca el archivo en Descargas del navegador y léelo antes de compartirlo.

Para tus observaciones, cambia a **Mis registros → Pegar o escribir un relato**. Prepara los borradores, revisa cada fuente, fecha y categoría, confirma y guarda. **Registros** permite añadir o corregir notas individuales. **Exportar** permite descargar resúmenes e imprimir en PDF si el navegador lo admite.

El selector admite chino simplificado, inglés, español, francés, japonés y coreano. Cambian la interfaz, la ayuda integrada y los ejemplos ficticios; cada idioma conserva sus modificaciones del ejemplo por separado. Tus registros no se traducen al cambiar de idioma. Los patrones locales de clasificación siguen siendo principalmente de chino e inglés, así que revisa manualmente las categorías y fuentes de los textos en otros idiomas.

Usa **Ajustes → Exportar copia** antes de borrar datos o cambiar de dispositivo. **Importar copia** sustituye los registros personales tras confirmar. Los datos se guardan sin cifrar en un navegador, sin sincronización automática. La prueba privada puede requerir iniciar sesión en la plataforma, pero no necesita Remote ni un ordenador conectado.

Esta prueba usa reglas locales, sin IA en línea, conclusiones clínicas automáticas, diagnóstico ni decisiones sobre medicación o ingreso hospitalario. Comprueba las fuentes antes de compartir.

## Français

Care Notes aide à organiser des récits de soins, à comparer des descriptions et à préparer une transmission ou une consultation. Il fonctionne dans le navigateur d’un téléphone, d’une tablette ou d’un ordinateur. Aucun paquet Android n’est encore publié.

1. Choisissez **Voir l’exemple**. Toutes les notes sont fictives. Vous pouvez ouvrir **Mode d’emploi** à tout moment.
2. Dans **Revoir un épisode**, sélectionnez les notes et examinez les questions à clarifier.
3. Un élément **peut appartenir à la même période de changement** n’est qu’un candidat à vérifier. Lisez les deux notes source avant de choisir **Relier ces deux notes** ou **Pas la même période** ; l’application ne les relie jamais automatiquement.
4. Ajoutez une note de vérification aux récits reliés et conservez les différences non résolues.
5. Choisissez **Télécharger la transmission**, puis relisez le fichier avant de le partager.

Pour vos propres observations, passez à **Mes notes**, puis collez ou saisissez un récit. Vérifiez la source, la date et la catégorie de chaque brouillon avant de confirmer et d’enregistrer. La chronologie permet aussi d’ajouter ou de corriger une note individuellement.

Le sélecteur de langue prend en charge le chinois simplifié, l’anglais, l’espagnol, le français, le japonais et le coréen. L’interface, l’aide intégrée et les exemples changent de langue ; les modifications des exemples sont enregistrées séparément. Vos notes personnelles ne sont jamais traduites lors d’un changement de langue. Les règles locales de classement restent principalement conçues pour le chinois et l’anglais : vérifiez manuellement les catégories et les sources en français.

Avant de changer d’appareil ou d’effacer le navigateur, utilisez **Paramètres → Exporter la sauvegarde**. Les notes sont stockées sans chiffrement dans un seul navigateur, sans synchronisation automatique.

Cette version d’essai utilise des règles locales. Elle ne fournit pas de diagnostic, de conseil de traitement, de décision d’hospitalisation ni de validation clinique. Vérifiez toujours les sources avant de partager un résumé.

## 日本語

Care Notes は、介護・ケアに関する複数の記述を整理して確認し、引き継ぎや受診用の資料を作るためのツールです。スマートフォン、タブレット、パソコンのブラウザで使えます。Android インストール版はまだ公開していません。

1. **サンプルを見る**を選びます。サンプルはすべて架空です。**使い方**はいつでも開けます。
2. **出来事を確認**で今回含める記録を選び、確認が必要な項目を見ます。
3. **同じ変化の期間かもしれません**という表示は確認候補にすぎません。2件の元記録を読んでから、**この2件を関連付ける**または**同じ期間ではない**を選びます。アプリが自動で関連付けることはありません。
4. 関連付けた記述には確認メモを追加し、解決できない違いはそのまま残します。
5. **引き継ぎをダウンロード**し、共有前に内容を読み直してください。

自分の観察を記録する場合は**自分の記録**へ切り替え、文章を入力または貼り付けます。下書きの情報源、日付、カテゴリを確認してから保存してください。

表示言語は簡体字中国語、英語、スペイン語、フランス語、日本語、韓国語に対応しています。画面、アプリ内ヘルプ、架空サンプルは切り替わりますが、自分で入力した記録は翻訳・置換されません。ローカルの分類パターンは主に中国語と英語向けなので、日本語の下書きはカテゴリと情報源を手動で確認してください。

端末やブラウザを変える前には**設定 → バックアップを書き出す**を使ってください。記録は1つのブラウザ内に暗号化されず保存され、自動同期はありません。

現在の試用版はローカルルールを使用し、診断、治療や服薬の助言、入院判断、臨床検証を提供しません。サマリーを共有する前に元の記録を確認してください。

## 한국어

Care Notes는 돌봄에 관한 여러 진술을 정리하고 비교해 인계 또는 진료 자료를 준비하는 도구입니다. 휴대전화, 태블릿, 컴퓨터 브라우저에서 사용할 수 있습니다. Android 설치 패키지는 아직 배포하지 않았습니다.

1. **예시 보기**를 선택하세요. 모든 예시는 가상 데이터입니다. **사용 방법**은 언제든 열 수 있습니다.
2. **사건 검토**에서 이번 인계에 포함할 기록을 고르고 확인할 질문을 살펴보세요.
3. **같은 변화 기간일 수 있습니다**는 검토 후보일 뿐입니다. 두 원본 기록을 읽은 뒤 **이 두 기록 연결** 또는 **같은 기간이 아님**을 선택하세요. 앱이 자동으로 연결하지 않습니다.
4. 연결한 진술에는 검토 메모를 추가하고 해결되지 않는 차이는 그대로 남기세요.
5. **인계 내용 다운로드**를 선택하고 공유 전에 파일 내용을 다시 확인하세요.

직접 관찰한 내용을 남기려면 **내 기록**으로 전환해 설명을 입력하거나 붙여넣으세요. 저장 전에 각 초안의 출처, 날짜, 분류를 확인해야 합니다.

표시 언어는 중국어 간체, 영어, 스페인어, 프랑스어, 일본어, 한국어를 지원합니다. 화면, 앱 내 도움말, 가상 예시는 언어에 따라 바뀌지만 사용자가 직접 입력한 기록은 번역되거나 대체되지 않습니다. 로컬 분류 패턴은 주로 중국어와 영어를 대상으로 하므로 한국어 초안의 분류와 출처는 수동으로 확인하세요.

기기나 브라우저를 바꾸기 전에는 **설정 → 백업 내보내기**를 사용하세요. 기록은 한 브라우저에 암호화되지 않은 상태로 저장되며 자동 동기화되지 않습니다.

현재 시험 버전은 로컬 규칙을 사용하며 진단, 치료·복약 조언, 입원 결정, 임상 검증을 제공하지 않습니다. 요약을 공유하기 전에 원본 기록을 확인하세요.


## Try a correction / 体验一次更正

From the episode page, open **Try evidence correction / 体验更正后的变化**. Read the fictional accounts, then use the date-correction button. The old same-event proposal is withdrawn while the original remains in version history. Editing any original text withdraws its old analysis until it is analysed again. This is a separate temporary workspace; reload resets it. Download the review JSON if needed. The static page uses local computation and authored example annotations, with no live model.

在“整理经过”页面打开“体验更正后的变化”。点击日期更正后，查看被撤回的暂定关联和保留的旧原文。自由修改文字后，原来依赖它的分析会失效，不能冒充已经理解新内容。本页是临时试验，不改变原有照护记录；刷新会重置，需要保留请下载材料。
