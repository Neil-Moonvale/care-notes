Care Notes helps a family review fragmented accounts without losing who said what,
what remains unknown, or which conclusions need revisiting after a correction.

## Download and try

- **Android:** download `Care-Notes-0.4.0-rc.1.apk` from the Assets below. Android 8.0+ with an updated System WebView. No desktop or Care Notes account is required.
- **Web example:** [open the fictional case](https://care-notes-neil.moonenchanter.chatgpt.site/?mode=demo). No key or login is needed for this example.
- **Instructions:** [English and Chinese guide](https://github.com/Neil-Moonvale/care-notes/blob/feature/evidence-revision-core/docs/USER_GUIDE.md). Six-language instructions are also in Settings.
- **Source:** use GitHub's source ZIP/TAR downloads for this tag. An APK is the installable app; the source archive is for developers.

Start with the example, open Review, and correct the date. Inspect which proposed
links are withdrawn and which original descriptions remain. The example's analysis
is prewritten; its correction effects run locally. It is not a live model demo.

For your own accounts, configure OpenAI, DeepSeek or a custom OpenAI-compatible
HTTPS endpoint in Settings. The app sends text only after explicit consent.
Model analysis needs your provider's credit; no shared API key is included.
The public hosted demo relays the two fixed official providers. Custom web
providers must permit browser requests (CORS). Android makes native HTTPS calls
and avoids that browser restriction.

## Included

- Accounts, Review and Settings in one phone workflow.
- Source versions, exact quotations, declared dependencies, uncertain times and proposed event relations.
- Correction-triggered withdrawal of dependent old analysis, followed by fresh review.
- Local records, full-history JSON backup/restore, text export, clipboard and print/PDF controls.
- Chinese, English, Spanish, French, Japanese and Korean interface, examples and in-app instructions.

The APK was compiled from `6538a6411b2093b5604f3892ffb273fabda1f793`, signed,
and verified with APK v2/v3 signature checks. The publication workflow checks its
checksum and compares every bundled app file with the web source, after running
the automated suite. The private signing key is not distributed.

## Read before relying on it

This is an installable **release candidate**, with a complete capture/review/export
workflow. Real-phone acceptance, live-model comparison and independent caregiver
evaluation remain outstanding. Engineering checks do not establish model accuracy.
Every model interpretation still needs review. Automatic sensor collection,
cross-device sync and personal clinical baselines are not included. The app does
not diagnose or recommend medication changes or hospital admission.

Data stays in the current app/browser unless you export it or consent to a model
request. Web and Android copies do not sync. Back up before uninstalling or clearing
data. Use fictional inputs when posting public feedback.
