## Changes / 更新

Includes the 1.3 clarification notebook: questions linked to exact source versions,
attributed replies saved as independent accounts, manual review, automatic recheck
after record/coverage changes, historical comparison, backup and handoff export.

Removes repeated follow-up suggestions when opposing claims lead to the same
question and the same source-version set. Both original accounts remain linked;
distinct questions and observation-gap suggestions remain available.

包含 1.3 的完整“待核对问题”功能。本修订消除同一问题、同一组原话产生的
重复建议，保留双方原话和独立的观察缺口问题，不自动裁定哪一方正确。
