# 1.2.0 — Handoff Change Review

Source update; not a signed APK release or hosted deployment.

After reviewing Results, a caregiver can retain a local checkpoint and later see newly added accounts, exact before/after corrections and withdrawn historical accounts. Declared observation coverage changes are flagged separately. A reviewed change list can be exported without AI. Checkpoints survive validated backup/restore; older backups remain compatible.

Validation:

- `npm test`: 154 passing tests (149 existing plus 5 focused checkpoint tests).
- `npm run test:worker`: build and actual workerd relay test passed.
- `npm run android:prepare`: 45 bundled assets prepared, including both new modules.
- Real headless Chromium at 390×844 and 1280×900: created an account, enforced review before checkpoint creation, saved and reloaded checkpoint, corrected original text, expanded before/after comparison, reviewed and downloaded the change list; no page errors or horizontal overflow.

Limits: one checkpoint, not delivery acknowledgement or synchronization; source/coverage comparison, not AI narrative diff or clinical change detection. English/Chinese feature copy with English fallback elsewhere. No new Android compilation/signing or physical-device acceptance, independent caregiver trial, or live-model accuracy test. Published 1.1.0 links are deliberately retained.
