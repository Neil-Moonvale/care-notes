## What changed

- Keep suggested clarification questions or create your own, linked to exact
  source versions. Suggestions retain supporting and opposing evidence.
- Save replies as new, attributed original accounts. Never overwrite the account
  being questioned or automatically treat a reply as verified.
- Explicitly review replies. Source additions, edits, withdrawals and coverage
  changes invalidate prior review snapshots and request another check.
- Compare historical/current wording, reopen a question, and retain review actions.
- Export questions and replies separately or within handoff text/clipboard/PDF.
- Restore questions through validated full-history backups; old backups still load.
- Chinese/English feature copy, English fallback for four other interface languages.
- Fix source creation on local HTTP origins that do not expose `crypto.randomUUID`.
- Add a project-root allowlist check to reduce accidental inclusion of unrelated
  work or private signing/configuration files.

## 中文说明

在“整理结果 → 待核对问题”保存问题，勾选相关原话，再记录“谁说了什么”。
回答会成为独立描述，原话仍保留。人工核对后，如果资料发生变化，会重新
提示核对。问题、回答、版本和核对记录可备份，也可一起导出交接。
**“已核对”不表示事实已证实。** 此流程无需 API，不自动改变 AI 结论。

本次发布源码和网页版；安卓正式签名包仍为 1.2.0，未冒用其他证书发布
覆盖安装包。旧版 APP 不支持新增问题记录，请勿把 1.3 备份经过旧版再次
导出，否则新增字段可能丢失。

## Validation and boundaries

- 173 automated tests passed, including 14 new clarification cases.
- Worker runtime integration passed; 47 Android assets prepared; 48 portable web
  assets verified byte-for-byte.
- Browser walkthrough: capture → question → attributed reply → human review →
  original correction → automatic recheck → reload persistence, in Chinese at a
  narrow viewport. A local HTTP ID-generation failure was reproduced and fixed.
- No physical Android device, live-model benchmark or independent clinical
  evaluation was performed. The review state is not a signed audit trail.
