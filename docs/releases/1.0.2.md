## Fixed

The hosted Worker rejected `redirect: error` before contacting a provider. This broke both model discovery and generation even with valid credentials. The Worker now uses manual redirects and rejects non-success responses without forwarding credentials. Native Android and browser-direct requests keep their existing redirect protections.

Official DeepSeek V4 requests explicitly select low reasoning effort within the existing token limit. Thinking remains enabled. The default high-effort behavior can leave too little output budget for the structured result. This option is not sent to custom services or unrelated models. There are no automatic paid retries.

## 使用

网页版刷新后，在设置中选择 DeepSeek，填写密钥，保留“通过本站转发”，点击“获取模型列表”。选择文字模型后，进入“AI 整理”运行。安卓版请更新到本页的 1.0.2。
