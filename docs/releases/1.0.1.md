## What changed

Enter the API key and custom base URL if needed, select **Get models**, then choose a text model from the returned list. No model ID is needed to fetch the list. Discovery sends no care records and requests no generated content. Manual entry remains available for services without a standard models endpoint.

The Android client uses a native HTTPS GET for model discovery. The web client exposes site relay or direct browser access for official providers. It no longer silently changes transport after an unavailable status probe. Errors distinguish browser-to-site failure from site-to-provider failure, authentication, forbidden model lists and unsupported endpoints. No automatic retries or provider changes.

## 中文操作

设置 → 选择服务商 → 填写密钥和地址 → **获取模型列表** → 下拉选择文字模型。然后到“AI 整理”开始使用。若网页版的本站转发失败，可以明确选择浏览器直连，或使用安卓版。浏览器直连仍要求服务商允许跨域。

## Verification and limits

117 automated checks pass, including GET-only discovery, fixed-provider relay boundaries, native bridge dispatch, model selection and stale response rejection. Provider responses in these checks are synthetic. This release does not claim that every provider or the reported live relay failure has been independently validated end to end. Use a text-capable model and review its output.
