## What was fixed

A short connection probe could pass while organization exhausted the output budget before producing JSON. DeepSeek discovery returned `deepseek-flash`, which missed the old version-prefix profile. A controlled four-source fictional test reproduced `finish_reason: length`: all 6000 output tokens were reasoning tokens, both with default and low effort.

Official DeepSeek requests now use its documented non-thinking mode across model aliases. The selected model still extracts the evidence; schema, quotation, version and uncertainty validation remain active. Custom services receive no vendor-specific settings. Output-limit errors are distinguished from other incomplete outputs. The connection label explicitly identifies a basic test. No paid request retries automatically.
