# Care Notes 1.0.6

- A single AI call now returns a plain-language report alongside structured extraction. Read short paragraphs first; expand exact source quotations when reviewing. At most three clarification questions follow the report.
- Reports are tied to a complete input snapshot. Adding, revising or deleting an account invalidates the previous narrative. Current reports survive backup/restore and appear in exports. Legacy backups remain supported.
- Six-language authored demos show the report without an API key and are explicitly labeled as examples. Saved model reports retain their generation language.

Validation: 127 automated tests, including custom Chat Completions, custom Responses and hosted transport with controlled responses; source-version rejection, report backup/restore, invalidation and export; the actual UI controller presents narrative and evidence. These checks do not establish live-model prose quality, semantic accuracy or complete Android hardware compatibility. No new live-model benchmark was run for this release.
