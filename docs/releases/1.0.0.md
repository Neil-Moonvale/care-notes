## What changed

- Four explicit screens: Accounts, AI organize, Results and Settings, with larger touch controls and coherent light/dark layouts.
- A visible Start AI organization button. The optional connection probe checks communication instead of blocking the app on one clinical extraction fixture.
- Dedicated results, source links and counts of extracted claims, event links and open questions.
- Persistent request progress and actionable errors; failed calls retain prior output and original records.
- Explicit custom-provider compatibility mode, continued schema/evidence checks, two-minute waiting and distinct timeout/cancellation messages.
- Same signing identity as 0.4.0-rc.1, updated Android versionCode, six-language instructions and retained local backups/history.

## Verification and limits

The automated suite covers protocol selection, consent, invalid-output rejection, source corrections, restored workspaces and the actual UI controller's request/results/error transitions with synthetic responses. The publication checks every bundled APK asset against source and verifies the APK checksum. Android is compiled by CI and the distribution is signed privately.

No live-provider benchmark or broad device acceptance is claimed. A valid response shape and quotation do not prove correct interpretation. Users must review results. The fictional demo does not call an AI. New-text AI organization requires the user's own API key and credit. There is no automatic diagnosis, medication advice, sensor collection or cross-device synchronization.

## 中文开始使用

先下载 APK，打开“体验示例”→“整理结果”。自己的材料在“描述”保存，在“设置”填写 API，然后在 **AI 整理** 页勾选同意并点 **开始 AI 整理**。成功后自动进入结果页；错误会保留在页面。退出后密钥需重新填写。升级前先导出完整备份。
