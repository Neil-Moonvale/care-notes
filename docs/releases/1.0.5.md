# Care Notes 1.0.5

- GLM-5.3 / Flash custom calls allow 24,000 output tokens including mandatory reasoning, with a visible budget and a four-minute timeout. No automatic paid retries. Earlier switchable GLM models use non-thinking mode only on recognized official endpoints. Arbitrary providers receive no GLM-specific fields.
- Android can explicitly save an endpoint-scoped API key using Android Keystore AES-GCM encryption. Keys stay out of record backups. Save and delete controls are available in Settings. Web remains session-only.
- Legacy UI access is shown only when this device contains legacy records, under a recovery explanation. Old records are not deleted.
