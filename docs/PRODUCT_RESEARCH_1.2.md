# Product research for 1.2.0

Reviewed 2026-10-20. These are product-positioning notes, not a comprehensive market survey or an application acceptance prediction.

## Open-source maintainer support

[OpenAI Codex for Open Source](https://developers.openai.com/community/codex-for-oss) supports maintainers with coding tools and potentially API credits/security access. Its public page invites core maintainers and widely used public projects, and asks projects outside the stated criteria to explain their ecosystem importance. Adding features alone does not establish eligibility or guarantee acceptance. The previous application's rejection rationale was not available.

Useful future evidence: reproducible releases, independent issue reports and contributions, documented user feedback with consent, and honest scope/limitations. Do not invent usage numbers, endorsements, clinical validation or application outcomes.

## Existing products and the chosen focus

[Caring Village's official feature page](https://caringvillage.com/app/) describes caregiver coordination and a wellness journal. [Lotsa Helping Hands](https://kp.lotsahelpinghands.com/how-it-works/) describes care coordination, a help calendar and community communication. Thus care diaries and collaborative care organization already exist.

The proposed focus for Care Notes is traceable reconstruction of fragmented accounts: preserve unknowns and conflicting statements, then show how original evidence changed between handoffs. Version 1.2 adds an inspectable before/after source comparison to the existing evidence coverage layer. These sources do not prove that no competing product has a similar feature, and this repository makes no exclusivity claim.

## Next evidence to collect

Ask independent testers, using fictional cases first, whether they can identify a corrected statement, distinguish historical wording from current wording, and find what is still unknown. Record failures and improve the workflow. This iteration has automated and browser checks, not independent caregiver validation.
