# Evidence Coverage Firewall: implementation checkpoint

Goal: never promote missing observations to an assertion that an event did not occur.
This implements the maintainer's detailed specification. No clinical inference or live sensor integration is added.

Architecture: shared deterministic browser/Node modules; source observation profiles are versioned separately from source text. Coverage is computed by intersecting declared and reviewed capabilities, active intervals, reporting cadence and clock uncertainty, then subtracting gaps. Model output cannot create or change capability contracts. Unreviewed declarations never authorize negative evidence. Sensor events need subject and event identity: a door opening is not a person leaving.

Report safety: final claim wording is generated by rules, with original quotes explicitly attributed. Unrestricted model paragraphs are not proof of entailment and cannot bypass the firewall. Unknown time, missing profiles or conflicting evidence fail closed. Negative evidence is bounded to the declared observation scope; even complete coverage does not verify medication ingestion. Existing quotations, dependencies and source revisions remain intact.
