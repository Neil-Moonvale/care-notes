# 照护手记

帮助家属把零散的照护描述整理成可核对的交接材料。保留原话、来源和不确定信息，不需要购买额外设备。

先看[使用指南](USER_GUIDE.md)。手机、平板和电脑浏览器都可以使用；当前是网页版，尚未发布安卓安装包。

## 使用顺序

1. 体验虚构示例，或在“我的记录”写一段观察。
2. 在“整理经过”选择相关记录，核对不同说法和缺失信息。
3. 下载交接内容，或通过“导出”准备复诊摘要。

应用右上角有“怎么用”。提供简体中文、英文和西班牙语，界面、帮助和示例跟随语言切换。真实记录保留原话。

## 数据与能力

数据保存在当前浏览器，没有自动跨设备同步。换设备前到“设置”导出备份；导入会在确认后替换当前真实记录。

当前试用版使用本地规则，没有启用在线 AI，不提供诊断或用药决定。保留原文有助于核对，不代表内容已经被证实。
