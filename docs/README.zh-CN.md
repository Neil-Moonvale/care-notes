# 照护手记

[English](../README.md) · [开发路线](ROADMAP.md) · [翻译指南](TRANSLATING.md)

帮助患者和家属整理照护信息的早期工具，保留原话、来源、不同说法和不确定性，方便复诊核对。尚未经过临床验证。

## 使用流程

1. 打开“体验示例”，点“一段话记下来”。
2. 填入虚构示例，点“本地整理（规则）”。
3. 核对每条的原文、类别、来源和日期，逐条勾选后保存。
4. 打开记录，在“原文依据”查看完整输入。
5. 在“复诊摘要”选择内容，核对后导出。

也可以直接“记一笔”。同一事件的不同记录仍需手动关联，软件不认定谁说得对。日期默认留空，相对日期需要人确认。

## 智能能力的真实状态

- 本地规则已可用：分段、类别和来源建议，不调用语言模型。
- AI 接口代码已实现：OpenAI 只建议固定摘录编号的标签，验证会拒绝新增、漏掉、重复或改写内容的返回结果。
- 当前手机试用站没有启用 AI 服务，未配置密钥、未进行真实模型评测。接口测试使用模拟返回结果，不是准确率。
- 诊断、药量建议、药效判断和危机评估不属于本工具的功能。

启用真实模型前需明确模型、费用、授权和数据处理方式。密钥只放服务端，不能放网页或公开仓库。

## 语言与数据

首发简体中文和英文，按浏览器语言选择，也可以手动切换。切换界面不会翻译或覆盖用户原话。其他语言的文字可以原样录入、导出，但本地中文/英文归类规则对其他语言没有效果保证。

记录存在当前浏览器，没有跨设备同步。本地整理不发送记录。仅在已配置 AI 服务并明确同意时，本次输入才会发送给服务端和模型提供方。

备份包含完整输入和更正历史，可能包含没有选进复诊摘要的文字。分享前请检查。本地保存不是加密；换设备、浏览器或网址前先备份。新版本导出备份格式 2，兼容导入格式 1；旧应用可能无法读取新备份。

## 开发者启动

无需安装依赖：运行 `python3 -m http.server 8000 --directory dist`，打开 `http://localhost:8000`。

可选 AI 服务需要 Node.js 22 及以上。配置自己的 `.env` 后运行 `node --env-file=.env server/index.mjs`。它只监听本机，不是已上线的多人云服务。详细限制见 [AI.md](AI.md)。

运行 `npm test` 可执行 27 项检查。未进行真实模型或手机浏览器端到端测试。
