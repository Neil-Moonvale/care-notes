## 面向谁

被照护者不能可靠主动记录、家人各自只知道一部分的家庭。帮助准备照护交接和复诊材料，不判断病情、用药或是否住院。新文字仍需要有人输入，或使用手机键盘的语音输入；没有自动传感器采集。

## 与直接总结的区别在哪里

原文版本、引用和依赖关系由系统维护；不只保存一段生成的文字。更正某条来源时，依赖其旧版的结果会退出当前经过。不同说法和不确定时间可以保留，关系作为待核对的提议展示。

这些机制是否在真实场景中比直接总结更有用，仍需要同模型、同材料的对比。协议兼容、格式校验和引用校验都不是理解正确的保证。
