## Draft: why this repository qualifies

Under the form's 500-character limit. Update as real evidence improves:

> Care Notes is an early open-source caregiving journal preserving original accounts, uncertainty and traceable visit summaries. Its independent evidence and draft-validation modules are reusable. The prototype has Chinese/English UI, local storage, reviewed paragraph capture and 27 regression checks. An optional AI adapter is implemented but not live-evaluated. I am developing it as the primary maintainer; adoption evidence is still being collected.

## Private information needed before submission

- Applicant's real first and last name.
- Email associated with the intended ChatGPT account; do not substitute a GitHub contact email or another Google login.
- Confirmation of primary/core maintainer role and actual responsibilities.
- Review and agreement to the current program terms.

Do not commit identity details, medical history, keys or a completed private application to this repository.

API credits and Codex Security are optional form interests. API credits require an OpenAI organization ID and use explanation. Published descriptions discuss coding, maintenance automation, releases and core OSS work. Do not assume credits can fund end-user medical inference without checking applicable terms.

The biggest missing evidence is actual use, ongoing maintenance and real-model evaluation. Additional languages alone cannot replace that evidence. The owner can choose to submit a truthful early application, with uncertain approval.
